Trending news, auto-posted

지금 뜨는 뉴스를 골라 Pubity 스타일 이미지와 릴스로 만들어 5시간마다 인스타그램에 자동으로 올리는 봇입니다. 이 페이지도 봇이 실행될 때마다 자동으로 업데이트됩니다.

마지막 업데이트 — 다음 실행 — 주기 5시간 게시물 0

최근 업로드

아직 업로드된 게시물이 없습니다. 첫 실행 후 여기에 표시됩니다.

작동 방식

트렌딩 뉴스 수집

Google News의 톱뉴스, 연예, 스포츠, 테크, 과학 섹션에서 최신 기사를 모읍니다.

AI가 바이럴 기사 선택

Google AI(Gemini)가 가장 공유될 만한 기사를 고르고, 짧고 강한 대문자 헤드라인, 캡션, 해시태그를 씁니다.

Pubity 스타일 디자인

위쪽은 기사 사진, 아래는 검은 패널에 굵은 헤드라인, 핵심 단어는 노란색으로 강조합니다.

릴스 자동 제작

9:16 세로 영상: 사진 줌인 효과, 헤드라인, 단계별 스토리 문장, 배경음악(선택)까지 넣습니다.

5시간마다 업로드

GitHub Actions가 5시간마다 실행해 피드 게시물 1개와 릴스 1개를 올리고, 중복 기사는 건너뜁니다.

이 페이지 자동 갱신

새 게시물이 저장소에 커밋되면 Cloudflare가 자동으로 다시 배포해 이 페이지가 업데이트됩니다.

기능

기능설명
뉴스 소스Google News RSS (키 불필요), 국가/언어 설정 가능 (NEWS_COUNTRY, NEWS_LANGUAGE)
AI 문구Google API 키 하나로 Gemini 사용 (GOOGLE_API_KEY). 키가 없으면 원본 제목으로 게시
피드 이미지1080×1350 (4:5), Anton 폰트, 강조 색상과 계정 핸들 설정 가능
릴스1080×1920, 기본 8초, H.264/AAC. assets/music에 mp3를 넣으면 랜덤 배경음악
업로드 방식instagrapi (아이디/비밀번호) 또는 공식 Instagram Graph API (비즈니스 계정)
일정GitHub Actions 크론 0 */5 * * * 또는 python main.py --loop
중복 방지올린 기사는 state/posted.json에 기록해 다시 올리지 않음
소스: instagram_auto/ · 뉴스 사진과 기사 저작권은 각 언론사에 있습니다.
