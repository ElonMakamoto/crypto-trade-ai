chedlab · instagram auto

Trending news, auto-posted

지금 뜨는 뉴스를 골라 Pubity 스타일 이미지와 릴스로 만들어, 정해진 시간마다 인스타그램에 자동으로 올리는 Windows 앱입니다. Google API 키와 인스타 토큰만 넣으면 됩니다.

⬇ Windows용 다운로드 Windows 10 / 11 · 설치 없이 바로 실행 · 최신 버전 자동

사용 방법

다운로드 후 실행

InstagramAuto.exe를 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.

정보 입력

Google API 키(무료 발급), 인스타 액세스 토큰(받는 법), 이미지에 넣을 계정명을 넣고 설정 저장 → 인스타 연결 확인.

미리보기 확인

미리보기만 만들기로 어떤 게시물과 릴스가 나오는지 먼저 확인합니다. 업로드는 하지 않습니다.

자동 업로드 시작

▶ 자동 업로드 시작을 누르면 바로 한 번 올리고, 이후 설정한 간격(기본 5시간)마다 올립니다.

인스타 토큰 받는 법

공식 API로 올리려면 액세스 토큰이 한 번 필요합니다 (무료, 약 10분). 받은 토큰은 앱이 알아서 연장하므로 다시 받을 필요가 없습니다.

프로페셔널 계정으로 전환

인스타 앱 → 설정 → 계정 유형 및 도구 → 프로페셔널 계정으로 전환 (크리에이터 또는 비즈니스, 무료).

Meta 앱 만들기

developers.facebook.com → 앱 만들기 → 사용 사례에서 Instagram에서 메시지 및 콘텐츠 관리를 고르고 만듭니다.

계정 연결

앱 대시보드 → Instagram → Instagram 로그인을 통한 API 설정 → 액세스 토큰 생성에서 계정 추가 → 인스타로 로그인하고 허용합니다.

토큰 붙여넣기

토큰 생성을 눌러 나온 토큰(IG로 시작)을 복사해 앱의 인스타 액세스 토큰에 붙여넣고 인스타 연결 확인을 누릅니다.

  • 계정 추가할 때 테스터 초대가 필요하다고 나오면: 앱 대시보드 → 앱 역할 → 역할 → Instagram 테스터에 내 계정을 추가하고, 인스타 앱 → 설정 → 앱 및 웹사이트 → 테스터 초대에서 수락하세요.
  • 공식 API는 사진을 PC에서 바로 올리는 기능이 없어서, Pubity 스타일 게시물 이미지는 6초짜리 정지 화면 릴스로 올라갑니다. 프로필 그리드에는 같은 디자인으로 보입니다.

기능

기능설명
트렌딩 뉴스Google News의 톱뉴스, 연예, 스포츠, 테크, 과학 섹션에서 최신 기사를 모읍니다.
AI 문구Google AI(Gemini)가 가장 바이럴할 기사를 고르고, 짧고 강한 대문자 헤드라인, 캡션, 해시태그를 씁니다.
Pubity 스타일 게시물위는 기사 사진, 아래는 검은 패널에 굵은 헤드라인. 핵심 단어는 강조 색상으로 표시하고 계정명을 넣습니다 (1080×1350).
릴스 자동 제작9:16 세로 영상: 사진 줌인 효과와 헤드라인, 단계별 스토리 문장. 음악 폴더를 지정하면 mp3를 랜덤으로 깔아 줍니다.
자동 업로드한 번에 게시물 1개 + 릴스 1개 (또는 하나만). 간격은 직접 정할 수 있고, 이미 올린 기사는 다시 올리지 않습니다.
업로드 방식공식 Instagram API (추천, 토큰 자동 연장). 아이디/비밀번호 방식도 있지만 인스타가 막을 때가 있습니다.
Windows 시작 시 실행체크하면 PC를 켤 때 앱이 자동으로 켜지고 자동 업로드도 바로 시작합니다.
안전한 저장비밀번호와 API 키는 Windows 암호화로 이 PC의 내 계정에만 저장됩니다.
자동 업데이트새 버전이 나오면 이 페이지의 다운로드가 자동으로 최신이 되고, 앱 안에도 "새 버전 받기" 버튼이 나타납니다.

알아 둘 점

  • PC가 켜져 있어야 자동 업로드가 됩니다. 창은 최소화해 두면 되고, 닫으면 멈춥니다.
  • 너무 자주 올리면 도달이 떨어질 수 있습니다. 간격은 4~6시간을 권장합니다. 공식 API는 하루 최대 50개까지 올릴 수 있습니다.
  • 뉴스 사진과 기사의 저작권은 각 언론사에 있습니다. 캡션에 출처는 자동으로 들어갑니다.
  • 만든 이미지와 영상은 앱의 결과 폴더 버튼으로 볼 수 있습니다 (%APPDATA%\InstagramAuto).
