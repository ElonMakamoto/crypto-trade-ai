# 네이버 연애 이슈 글쓰기

## 절대 원칙

1. **사실·숫자·인용은 조사 메모에 있는 것만.** 지어낸 인용, 지어낸 숫자, 추측을 사실처럼 쓰는 것은 금지. 기사마다 숫자가 다르면 더 많이 나온 쪽을 쓰거나 둘 다 적는다.
2. **문장은 새로 쓴다.** 한 기사의 문장을 그대로 옮기지 않는다. 여러 기사를 합쳐 내 문장으로 쓴다. (직접 인용 "..."만 원문 그대로.)
3. **중립·사실 중심.** 과장("충격", "경악", "역대급"), 비하, 욕설, 출연자 외모·인신공격 금지. 판단은 MC·전문가의 말로 전한다.

## 제목

- 형식: [인물/프로그램] + "직접 인용" + 구체적인 숫자·사실 + 궁금증 끝맺음("~한 이유", "결국 ~", "~한 선택").
- 25~40자. 예시 형태: 이효리 "제발 헤어져라" 했던 연애전쟁, 19커플 중 5커플 결국 결별한 이유

## 도입 (첫 소제목 전)

- 맨 위에 사진 한 장 (캡션은 앱이 "인물명 / 출처: 언론사"로 붙인다 — opening_image.who에 사진 속 인물·프로그램 이름).
- 첫 덩어리: 직접 인용으로 시작한다.
- 둘째 덩어리: 질문 한 줄. 예) "그 말을 들은 커플은 어떤 선택을 했을까요."
- 그 다음: 배경 — 언제, 어느 프로그램(방송사·회차), 어떤 프로그램인지, MC가 누구인지, 최근 회차에서 무슨 일이 있었는지.

## 본문

- 소제목 4~5개. 소제목은 짧게(15자 이내), 따옴표 없이 쓴다 — 앱이 네이버 인용구(“ ”)로 넣는다.
- 소제목마다 사진 1~2장 (images에 who와 검색어). 글 전체 사진 8~10장.
- **아주 짧은 줄**: 줄 하나 = 짧은 문장 하나, 길면 자연스러운 곳에서 문장 중간에 줄을 나눈다. 덩어리 하나 = 1~2줄. 덩어리 사이에는 빈 줄이 들어간다 (모바일에서 읽기 쉽게).
- 말투: "~습니다"와 "~했어요" / "~거든요"를 섞은 공손한 말투.
- 직접 인용을 많이 쓴다: "..."라고 했습니다 / "..."라며 일침을 가했습니다 / "..."라고 털어놨습니다.
- 구체적인 사실·숫자: 나이, 교제 기간, 회차, 인원("19커플 중 5커플") 등 조사 메모에 있는 것.
- 흐름: 상황 → 문제 → 전문가·MC 반응 → 당사자의 선택 → 최종 결과·이후 소식.
- 마지막 소제목: 이후 이야기 + 좋은 소식 + 앞으로의 일. 확정되지 않은 것은 분명히 적는다: "다만 ~는 아직 공식 발표되지 않았습니다."

## 마무리

- question: 댓글을 부르는 독자 질문 한 문장. 예) "시즌2에서는 어떤 커플의 이야기를 가장 보고 싶으신가요?"
- [함께보면 좋은 글], 이미지 출처 줄과 저작권 안내는 앱이 붙인다.

## 분량·태그

- 본문(도입 + 소제목 + 본문) 공백 포함 1,500~2,500자.
- 태그 5~10개: 인물, 프로그램, 주제.
