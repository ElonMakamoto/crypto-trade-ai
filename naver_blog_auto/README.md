# naver_blog_auto

네이버 블로그 **여러 계정**에 한국어 글을 자동으로 써서 올리는 **Windows · Linux 앱**입니다.
계정마다 **네이버에 한 번만 로그인해 두면**, 그 다음부터는 앱이 정해진 시간에 알아서 키워드를 고르고, 네이버·구글 연관검색어를 모아 넣고, 사진 4~6장과 함께 발행합니다. 글은 **무료 Google API 키(Gemini)** 로 씁니다.

- 직접 받기: [NaverBlogAuto.exe](https://github.com/ElonMakamoto/crypto-trade-ai/releases/download/naver-blog-auto-latest/NaverBlogAuto.exe) (`main`에 머지되면 자동으로 빌드됩니다)

## 화면

- 계정마다 위쪽 **탭**이 하나씩 있습니다. **➕ 계정 추가**로 최대 6개까지 넣을 수 있고, 계정 1이 아닌 계정은 **🗑 계정 빼기**로 목록에서 뺄 수 있습니다 (로그인·설정·기록은 남아 있어서 다시 추가하면 그대로 돌아옵니다).
- 오른쪽 위 **⚫ 블랙 · 🟢 그린 · ⚪ 화이트**로 배경을 바꿉니다 (저장됨).
- **⬆ 업데이트** 버튼: 누르면 새 버전을 확인해서 바로 받고(진행 막대) 다시 켭니다. 이미 최신이면 **다시 설치**도 할 수 있습니다.

## Linux에서 쓰기

- **프로그램 받기**: [NaverBlogAuto-linux](https://github.com/ElonMakamoto/crypto-trade-ai/releases/download/naver-blog-auto-latest/NaverBlogAuto-linux)를 받아서
  `chmod +x NaverBlogAuto-linux` 후 `./NaverBlogAuto-linux` 로 실행합니다 (Ubuntu 22.04 이상과 비슷한 배포판).
- **소스로 실행**: `naver_blog_auto/run_linux.sh` — 처음 한 번 필요한 것을 설치하고 앱을 켭니다 (`python3-tk`, `python3-venv` 필요).
- 글쓰기 브라우저는 Chrome → Edge → Chromium 순서로 찾고, 셋 다 없으면 Chromium을 처음 한 번 자동으로 받습니다.
- 한글 글꼴이 없는 시스템이면 앱에 들어 있는 Noto Sans KR을 사용자 글꼴 폴더에 설치합니다.
- 설정·로그인·결과는 `~/.local/share/NaverBlogAuto/`에 저장됩니다 (Linux에는 DPAPI가 없어서 API 키는 암호화 대신 본인만 읽을 수 있는 파일 권한으로 보호합니다).
- **⬆ 업데이트** 버튼과 1시간마다 자동 업데이트, **컴퓨터 시작할 때 자동 실행**(데스크톱 자동 시작 항목)도 Windows와 똑같이 동작합니다.
- 화면(데스크톱)이 없는 서버에서는 창 대신 `python main.py --account a` 같은 명령줄로 쓸 수 있습니다 (브라우저는 숨겨서 실행).

## 사용 방법

1. `NaverBlogAuto.exe`를 실행합니다. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
2. 오른쪽 위 **⚙ 공통 설정**에 **Google API 키**를 넣습니다 ([AI Studio에서 무료 발급](https://aistudio.google.com/apikey)) → **키 확인**.
3. 계정 칸마다 **🔑 네이버 로그인**을 누릅니다. 열린 브라우저(Edge)에서 네이버에 로그인하면 창이 저절로 닫히고 `blog.naver.com/아이디`가 표시됩니다. **'로그인 상태 유지'를 꼭 체크**하세요. 비밀번호는 앱에 저장되지 않습니다 (로그인은 계정별 브라우저 프로필에만 남습니다).
4. **👁 미리보기**로 글을 하나 만들어 봅니다. 브라우저로 미리보기 페이지(SEO 점수 + 글 + 사진)가 열립니다. 마음에 들면 **📤 미리본 글 올리기**.
5. **▶ 자동 시작**을 누르면 매일 업로드 시간(최대 3개, 한국시간)의 **앞뒤 40분 안 랜덤한 시각**에 한 편씩 올립니다.
6. (선택) ⚙ 공통 설정에서 **Windows 시작할 때 자동 실행**을 켜면 PC를 켤 때 앱이 켜지고 자동 업로드도 시작됩니다.

PC가 켜져 있는 동안만 동작합니다. 창은 최소화해 두면 되고, 닫으면 멈춥니다.

## 글 형식: 기사형 (모든 카테고리 기본)

계정 설정의 **글 형식**이 기본으로 **기사형**입니다. 아래 연애 카테고리와 같은 모양(인용 제목, 짧은 줄 가운데 정렬, 네이버 인용구 소제목 앞뒤 빈 줄 2개, 기사 사진과 출처 캡션, 마지막 출처 안내)으로 모든 카테고리(건강·의학, 재테크, 생활 정보 등)를 씁니다. 예전 SEO 정보형은 **글 형식 → SEO 정보형**으로 고를 수 있습니다.

- 건강·의학 글은 기사와 공식 기관 발표만 전하고, 진단·처방처럼 쓰지 않으며, 마지막에 "증상이 있으면 전문의와 상담하세요"를 넣습니다.
- 블로그 **chedamso**로 로그인하면 한 번 자동으로 주제 **건강·의학 상식**, 카테고리 **나와의관계**, 기사형으로 맞춥니다 (그 뒤 바꾼 설정은 그대로 둡니다).

## 🛡 저품질 예방 (계정마다, 기본 켜짐)

- **품질 기준**: 형식 점수 75점 미만, 본문 1,300자 미만, 사진 0장, 위험 단어(도박·대출·성인·광고 문구, 건강 글의 "완치·100% 효과·부작용 없음·특효")가 있으면 **공개하지 않고 임시저장**합니다. 진행 기록에 이유가 나옵니다.
- **속도**: 하루 최대 글 수(기본 2개)를 넘기거나 마지막 글 뒤 3시간이 안 됐으면 그 회차는 쉽니다.
- **직접 만든 이미지**: 기사형 글마다 앱이 만든 정리 카드를 한 장 넣습니다 (퍼온 사진만 있는 글은 성의 없는 글로 보일 수 있어요).
- 글쓰기 규칙: 기사 문장을 이어 붙이지 않고 새로 쓰기, 광고·외부 링크·연락처 금지.
- 이미 저품질에 걸린 블로그라면: 며칠은 하루 1개로 줄이고, 짧거나 사진 없이 올라간 글은 비공개로 돌려 두는 것을 권합니다.

## 💕 연애 카테고리 (기사형 글)

계정 칸의 **이번 글 카테고리**에서 고릅니다: 연애예능 이슈(연애전쟁·나는솔로·환승연애 등), 스타 연애·결혼·결별 소식, 연애 고민·심리, 커플 갈등·이별, 썸·고백, 결혼·돌싱 이야기. 이 카테고리들은 일반 SEO 글 대신 **연애 이슈 기사형**으로 씁니다 (규칙: [`skills/naver-love-story/SKILL.md`](skills/naver-love-story/SKILL.md)).

- **이야기 고르기**: 카테고리마다 정해진 검색어(예: 연애예능 → 연애전쟁, 나는솔로, 환승연애, 솔로지옥…)로 최근 3일 기사를 모아, 여러 언론이 함께 다룬 가장 최근 이야기를 고릅니다.
- **조사**: 구글 검색으로 여러 언론 보도를 비교해 사실·숫자·직접 인용만 모읍니다. 문장은 새로 쓰고, 인용과 숫자는 기사에 있는 것만 씁니다.
- **제목**: [인물/프로그램] + "직접 인용" + 숫자·사실 + "~한 이유"/"결국 ~", 25~40자.
- **도입**: 사진 + 회색 캡션 "인물명 / 출처: 언론사" → 인용 → 질문 → 언제·어느 프로그램·MC·최근 회차.
- **본문**: 소제목 4~5개를 네이버 **인용구(“ ”)**로, 소제목마다 사진 1~2장(글 전체 8~10장)과 캡션, 1~2줄씩 짧은 줄 + 빈 줄, 상황 → 문제 → MC·전문가 반응 → 선택 → 결과, 마지막에 "아직 공식 발표되지 않았습니다".
- **마무리**: 독자 질문, 작은 글씨 footer(이미지 출처, 저작권, 무단 전재·AI학습 금지). 다른 글 링크는 넣지 않습니다.
- **사진**: 조사한 기사들의 사진(대표 사진 + 본문 사진)을 받아 중복을 빼고 씁니다. 캡션의 이름은 기사 제목에 나온 이름·프로그램명으로 붙입니다.
- **형식 검사(100점)**: 제목 형식·길이, 도입 질문, 소제목 수, 분량(공백 포함 1,500~2,500자), 짧은 줄, 인용 4개 이상, 숫자, "아직 ~" 문장, 독자 질문, 태그 5~10개, 과장 표현. 85점 미만이면 고칠 점을 주고 최대 2번 다시 씁니다.
- **네이버 카테고리**: ⚙ 공통 설정 → **📁 카테고리 연결**에서 앱 카테고리마다 올릴 네이버 블로그 카테고리 이름을 정합니다 (기본: 연애예능 이슈, 스타 연애·결혼, 연애 고민·심리, 커플 갈등·이별, 썸·고백, 결혼·돌싱 이야기 — 블로그에 같은 이름의 카테고리를 만들어 두세요).
- 기사 사진의 저작권은 각 언론사·방송사에 있습니다. 출처를 적어도 저작권 신고 대상이 될 수 있으니 판단해서 쓰세요.

## 검색에 잘 걸리게 하는 장치

1. **연관검색어 수집 (매번)**: 네이버 자동완성 + 네이버 연관검색어 + 구글 자동완성을 모아 순위를 매기고, 상위 6개는 **원래 형태 그대로 반드시** 넣고, 다음 8개는 FAQ·본문에 녹입니다.
2. **최신 정보 조사**: Gemini의 구글 검색 기능으로 최신 사실·숫자·날짜를 조사하고 최근 뉴스 제목을 더해, 그 안의 사실만 씁니다.
3. **글쓰기 규칙 = 스킬**: [`skills/naver-seo-writer/SKILL.md`](skills/naver-seo-writer/SKILL.md)가 Gemini의 시스템 지시문으로 그대로 들어갑니다. GitHub의 [content-engine 스킬](https://github.com/affaan-m/everything-claude-code/tree/main/skills/content-engine)(MIT, 원본은 [`skills/content-engine/`](skills/content-engine/))의 원칙 — 자료에서 출발, 글 하나에 주장 하나, 형용사보다 구체성, 낚시 금지, 품질 검사 — 을 네이버 블로그용으로 옮긴 것입니다. `%APPDATA%\NaverBlogAuto\skill.md`를 만들면 그 파일이 대신 쓰입니다.
4. **SEO 점수 검사 (100점)**: 제목 앞쪽 키워드, 제목 길이, 분량, 키워드 반복(너무 적거나 많지 않게), 첫 문단 키워드, 소제목 4~7개, 연관검색어 포함률, 금지 표현(“알아보겠습니다” 같은 AI 티), 문단 길이·반복 문장, 태그 10개. **85점이 안 되면 고칠 점을 AI에게 주고 최대 2번 다시 쓰게** 해서 가장 높은 점수의 글을 씁니다.
5. **중복 글 방지**: 두 계정의 이전 글들과 문장이 30% 넘게 겹치면 다시 씁니다. 한 계정이 쓴 키워드는 다시 쓰지 않고, 다른 계정이 30일 안에 쓴 키워드도 피합니다.
6. **사진 4~6장**: 글 **맨 위(썸네일)·중간·맨 끝에 글 내용과 관련된 실제 사진**, 그리고 한눈에 정리 카드. 사진은 Pixabay/Pexels(키가 있으면) 또는 출처 표기 없이 써도 되는 공개 사진(Openverse)에서 찾고, 못 찾으면 AI 그림 → 디자인 카드. 카드는 글마다 색과 질감이 달라 같은 이미지가 반복되지 않고, 파일 이름에 키워드가 들어갑니다. 사진 아래 설명에도 키워드를 자연스럽게 넣습니다.
7. **검색 노출 추적**: 6시간마다 올린 글의 **네이버 블로그탭 순위**와 **통합검색 노출 여부**를 확인합니다 (📈 올린 글·검색 노출). 키워드를 AI가 고를 때 상위에 오른 키워드 방향은 더 쓰고, 노출이 안 된 방향(경쟁이 센 키워드)은 피합니다.
8. **자연스러운 발행**: 업로드 시간이 매일 ±40분 랜덤이고, 두 계정은 동시에 올리지 않습니다. 하루 최대 3개.

## 동작 순서 (한 편)

키워드 고르기 → 연관검색어 수집 (네이버·구글) → 최신 정보 조사 → 글쓰기 (스킬) → SEO 점수 검사·보완 → 중복 검사 → 사진 4~6장 → 미리보기 페이지 → 브라우저로 네이버 글쓰기 화면을 열어 제목·본문·사진·태그 입력 → 발행 (또는 임시저장) → 기록

글쓰기 화면 입력은 단계마다 확인합니다 (본문이 실제로 들어갔는지, 사진이 올라갔는지). 붙여넣기가 안 되면 다른 방법(붙여넣기 이벤트 → 직접 타이핑)으로 자동으로 바꿉니다. 실패하면 그 화면을 `오류 화면(error.png)`으로 결과 폴더에 저장하고 20분 뒤 한 번 더 시도합니다.

## 저장 위치

| 내용 | 위치 |
|---|---|
| 설정 (API 키는 Windows DPAPI로 암호화) | `%APPDATA%\NaverBlogAuto\settings.json` |
| 네이버 로그인 (계정별 브라우저 프로필) | `%APPDATA%\NaverBlogAuto\profiles\a`, `...\b` |
| 글·사진·미리보기·post.json | `%APPDATA%\NaverBlogAuto\output\` (앱의 **📂 결과 폴더**) |
| 올린 글 기록·검색 순위 | `%APPDATA%\NaverBlogAuto\state\` |

## 자동 업데이트

`naver_blog_auto/`가 바뀌어 `main`에 머지되면 `.github/workflows/naver-blog-auto-windows.yml`이 Windows용 `.exe`를 빌드하고, 셀프 테스트(이미지·SEO·파서 + Edge로 가짜 SmartEditor에 실제로 입력/발행)를 통과하면 `naver-blog-auto-latest` 릴리스로 올립니다. 앱은 켤 때와 **1시간마다** 릴리스의 `version.txt`로 새 버전을 확인해, 올리는 중인 글이 끝나면 스스로 교체·재시작합니다 (자동 업로드 중이었으면 다시 켜진 상태로). 오른쪽 위 **🔄 업데이트 확인** 버튼으로 바로 확인·설치할 수도 있습니다. 설정·로그인·기록은 `%APPDATA%`에 있어서 업데이트해도 그대로입니다. 파일 교체는 백신 검사 등으로 잠겨 있으면 최대 2분 동안 다시 시도하고, 다시 켜진 뒤 진행 기록에 '✅ 업데이트 완료' 또는 실패 안내가 나옵니다.

## 개발자용 (Python으로 실행)

```bash
cd naver_blog_auto
pip install -r requirements.txt
python app.py                                  # 데스크톱 앱
python main.py --account a --login             # 계정 1 네이버 로그인
python main.py --account a --dry-run           # 글+사진+미리보기만 (올리지 않음)
python main.py --account a --keyword "키워드"   # 그 키워드로 한 편 올리기
python main.py --account a --ranks             # 올린 글 검색 순위 확인
python selftest.py                             # 셀프 테스트
```

## 파일

| 파일 | 역할 |
|---|---|
| `app.py` | Windows 데스크톱 앱 (tkinter): 계정 2개, 설정, 자동 업로드, 기록, 자동 업데이트 |
| `main.py` | 한 편의 흐름 (글 → 사진 → 발행 → 기록), 검색 순위 확인 |
| `writer.py` | 주제·키워드 고르기, 조사, 글쓰기, SEO 보완 (Gemini + 스킬) |
| `keywords.py` | 네이버·구글 자동완성/연관검색어, 구글 트렌드, 뉴스, 네이버 검색 순위 |
| `seo.py` | SEO 점수 검사와 중복 검사 |
| `images.py` | 대표 이미지·소제목 사진·정리 카드 (AI 그림 / 무료 사진 / 디자인 카드) |
| `render.py` | 에디터에 넣을 블록과 미리보기 페이지 |
| `naver.py` | 브라우저(Edge/Chrome)로 로그인 유지, SmartEditor 입력, 발행 |
| `gemini.py` | Gemini API (모델 자동 선택, 무료 한도 대기·재시도, 구글 검색 조사, 그림) |
| `skills/` | 글쓰기 스킬 (네이버판 + content-engine 원본) |
| `selftest.py`, `tests/mock_editor.html` | 셀프 테스트와 가짜 SmartEditor |

## 주의

- 네이버는 블로그 글쓰기 공개 API가 없어서, 사람이 쓰듯 브라우저로 글쓰기 화면에 입력합니다. 네이버가 글쓰기 화면을 바꾸면 입력이 실패할 수 있습니다 (실패 화면이 결과 폴더에 저장되니 알려 주세요).
- 네이버 운영정책은 프로그램을 이용한 대량·반복 게시를 제한합니다. 계정 보호를 위해 **계정당 하루 1~2편**, 처음 며칠은 **임시저장 모드**로 글을 확인한 뒤 발행하는 것을 권장합니다. 다른 사람의 글·사진을 베끼지 않도록 AI는 조사한 사실로 새 문장을 쓰고, 경험담은 내 메모에 있을 때만 씁니다.
- AI가 쓴 사실(금액·날짜·조건)은 틀릴 수 있습니다. 돈·건강·법 관련 글은 공식 출처를 한 번 확인하세요.
- 무료 Google 키는 분당·하루 요청 수 제한이 있습니다. 한 편에 3~6번 요청하므로 하루 몇 편은 충분합니다. 한도에 걸리면 앱이 기다렸다가 다시 시도하거나 다른 Gemini 모델로 바꿉니다.
