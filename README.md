# Crypto Trade AI

AI-powered trading assistant that studies the **Top 1-10 cryptocurrencies by market cap** and helps with trading decisions.

## Features
- Live top 10 crypto by market cap
- Price, 24h change, volume, market cap
- Simple AI-style trading insights (based on momentum, volume, and basic signals)
- Easy management via this website + GitHub

## Live Site
(Coming soon - will deploy to Cloudflare Pages)

## Data Source
CoinGecko free API (no key required for basic market data)

## How it works
1. Fetches current top 10 coins by market cap
2. Analyzes 24h change, volume, and rank
3. Generates simple trading suggestions (not financial advice)
